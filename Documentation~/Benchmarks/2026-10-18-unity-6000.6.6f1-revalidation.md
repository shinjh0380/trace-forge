설치된 Editor는 `C:/Program Files/Unity/Hub/Editor/6000.6.6f1/Editor/Unity.exe`, 실제 로그의 revision은 **d20c9ac777da**, Windows x64다. 호스트 `run-tests.ps1`의 `$UnityExe` 버전 한 줄만 바꿨다. 원본 runner, Assets/Packages/ProjectSettings 및 해시는 `.worktrees/native-logger-test-host/.approval-20261018-unity600066/`에 보존한다. Library/Temp를 해당 디렉터리에 이동하고 process-local `BEE_CACHE_DIRECTORY`를 새 빈 `Bee.isolated`로 설정한 뒤 표준 명령을 실행했다. 종료 시 환경 변수는 원래 값으로 복원했다.

```powershell

```

Editor는 실제 `Csc .../TraceForge.Runtime.dll`을 실행했고 캐시 적중 결과로 대체하지 않았다. **Unity exit1**, Runtime 컴파일 실패로 XML이 생성되지 않았다. 테스트가 실패한 것이 아니라 **테스트 실행 전 컴파일 단계가 실패**한 결과다. 전체 네 assembly의 성공적인 재컴파일이나 테스트 통과를 주장할 수 없다.

로그에 같은 진단이 compiler 출력과 종료 요약으로 반복되므로 위 수는 중복을 제거한 **위치 수**다. 새 Editor 호환성 수정이나 경고 억제는 이번 재검증에서 하지 않았다. PlayMode도 같은 Runtime assembly를 필요로 하므로 알려진 컴파일 실패 후 실행하지 않았다. 할당 테스트 역시 새 버전에서 실행되지 않았다.

전체 테스트 선행 검증이 막혀 **benchmark process0, 완료0/20**, producer/completion/GC/행수의 새 원시 결과는 없다. 기준 worktree는 준비했으나 Unity로 열거나 측정하지 않았다. 성공 값의 제외·추가 sampling·재실행은 없다. 이전 6000.3 테스트나 guard 수치를 이 버전의 대체 결과로 사용하지 않는다.
